# Compute

**Being considered, not built.** Storage stays the main idea.

A group's machines are mostly idle, and the network, the member list and
per-person accounting that storage uses could let a member's machine do
work for the others too: transcoding video first, perhaps photo previews,
building websites or running a language model later.

It would be an option: off unless a machine's owner turns it on, with
limits they set, and running only fixed kinds of job, never other people's
programs. Unlike a stored shard, a job's file can be seen by the machine
that works on it, so jobs would go only to machines their owner chooses.
