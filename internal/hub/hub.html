yggstore box

Keep your files safe on this box: put them in a folder on your computer or phone, and they are stored, encrypted, on the group's machines.

Set up your computer or phone

1

Install Syncthing

Syncthing is a free program that keeps a folder on your device in step with this box. Install it once:

Windows
  1. Go to syncthing.net/downloads.
  2. Under Windows, download Syncthing Windows Setup and run it. Accept what it suggests.
  3. When it has finished, Syncthing opens in your web browser. If it doesn't, open 127.0.0.1:8384.
Mac
  1. Go to syncthing.net/downloads.
  2. Under macOS, download the Syncthing app, open the file and drag Syncthing into Applications.
  3. Open Syncthing from Applications. Its icon appears in the menu bar at the top of the screen: click it and choose Open.
Linux (Ubuntu, Debian, Raspberry Pi OS)
  1. Open a terminal and run: 
    sudo apt install syncthing
systemctl --user enable --now syncthing
  2. Open 127.0.0.1:8384 in your browser.
Android phone or tablet
  1. Install Syncthing-Fork from Google Play or F-Droid.
  2. Open it and allow what it asks for (storage, and running in the background).
iPhone or iPad

There is no official Syncthing for iPhone. Möbius Sync from the App Store works the same way (it is a paid app made by others).

2

Connect to this box

  1. In Syncthing, click + Add Remote Device (bottom right; on a phone, the Devices tab, then +).
  2. Under Device ID, this box may be listed among the nearby devices: click it. If it isn't, copy this box's ID and paste it in: 
    (waiting for this box's Syncthing)
  3. Under Device Name, type this box's name.
  4. Open the Advanced tab. Under Addresses, replace what's there with this, so your device finds the box even when it isn't listed nearby: 
    …
  5. Click Save.
  6. Within half a minute this box welcomes your device, and Syncthing shows a message: "this box wants to share folder yggstore (this box)". Click Add.
  7. Choose where the folder goes on your device (Folder Path, in the General tab), for example a folder called yggstore in your home folder. Click Save.

Your device must be on the same network (the same Wi-Fi or router) as this box when you connect.

3

Use the folder

  • To keep a file safe, put it in the files folder inside it, in folders of your own if you like. A few seconds later it is stored on the group's machines, and in the folder it is replaced by a small file ending in .ystub. Keep that: it is how you get the file back.
  • To get a file back, copy its .ystub into the restore folder. The file appears in the restored folder, in the same folders it has in files.
  • To delete a file for good, put its .ystub (or a copy) into the delete folder.
